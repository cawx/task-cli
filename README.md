# task tracker cli.

basic task tracker cli project made in java. features include:
- [x] adding, deleting and updating tasks.
- [x] listing tasks via optional status parameters.
- [x] creates json file if it doesnt exist.

## built with

* [java](https://www.java.com/en/) (23) - the programming lang
* [gson](https://github.com/google/gson) - json serialization & deserialization
